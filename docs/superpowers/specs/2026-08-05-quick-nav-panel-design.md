# 우측 고정 퀵링크 패널 설계

## 배경

`index.html`은 상단에 AI 멀티 에이전트 협업 방법론(01~07 섹션)을 길게 설명하고, 실제 프로젝트 GitHub 링크는 페이지 맨 하단 `프로젝트 & 링크` 블록에만 있다. 방문자가 끝까지 스크롤하지 않으면 프로젝트를 못 볼 수 있다는 문제를 해결하기 위해, 스크롤 위치와 무관하게 항상 접근 가능한 우측 고정 퀵링크 패널을 추가한다.

기존 하단 `프로젝트 & 링크` 블록(`.links-block`)은 README·플레이 영상 안내(`notice`)를 포함한 상세 버전으로 그대로 유지한다. 새 패널은 빠른 접근용 보조 수단이다.

## 구성 요소

- **패널**: 화면 우측에 `position: fixed`, 세로 중앙 정렬 (`top: 50%; transform: translateY(-50%)`).
- **링크 5개**: 기존 하단 블록과 동일한 저장소 — Project Lair · Project CP · Project Skill(Unity) / Unreal Skill Project · Project RPG(Unreal). 각 항목은 엔진 배지(기존 `.engine-unity` / `.engine-unreal` 색상 재사용) + 프로젝트명, `target="_blank" rel="noopener"`로 새 탭 오픈.
- **토글 버튼**: 패널 상단에 부착된 작은 화살표 버튼. 클릭 시 링크 목록이 사라지고 토글 버튼만 남는 축소된 탭 형태로 전환. 같은 위치(우측 중앙)에 계속 떠 있다가 다시 클릭하면 펼쳐진다.

## 노출 규칙

- 화면 너비와 무관하게 **항상 펼친 상태로 시작**한다 (좌우 여백이 없는 좁은 화면·모바일 포함). 미디어쿼리로 숨기지 않는다.
- 좌우 여백이 없는 화면에서는 패널이 본문 위에 겹쳐 뜰 수 있다 — 의도된 동작이며, 거슬리면 사용자가 토글 버튼으로 직접 접는다.
- 겹침이 자연스럽도록 패널에 반투명 배경 + 그림자를 줘서 "떠 있는 패널"임을 시각적으로 드러낸다.

## 상태 관리

- 순수 CSS만으로는 "항상 노출 + 사용자 클릭으로만 접힘" 요구를 만족할 수 없으므로 최소한의 JS로 클래스 토글을 구현한다 (기존 `<script>` 블록의 IIFE 패턴을 따름).
- `localStorage` 등 상태 저장은 하지 않는다. 새로고침/재방문 시 항상 펼친 상태로 리셋된다.

## 스타일 일관성

- 패널 카드와 링크 항목은 기존 `.agent` / `a.link` 카드의 다크 톤(`--bg-card`, `--border`, hover 시 밝아짐)을 그대로 따른다.
- 새로운 색상 변수를 추가하지 않고 기존 `:root` 팔레트만 사용한다.

## 범위 밖

- 패널 접힘 상태의 영속성(로컬스토리지)은 다루지 않는다.
- 하단 `프로젝트 & 링크` 블록의 구조 변경은 다루지 않는다.
- 모바일 전용 별도 레이아웃(예: 하단 고정 바)은 다루지 않는다 — 동일한 고정 패널을 그대로 쓴다.
